📝 错题录入整理

上传卷子 → 识别拆题 → 勾选做错的题，自动收拢成「我的错题集」。（本版只做录入整理，暂不做分析）

⚠️ 本版本仅供本地测试，请勿部署成公开网址或分享，key 会暴露。
⚙️ 通义千问 API Key
Key 仅保存在浏览器内存，不写入 localStorage，刷新页面后需重新填写。 填入 Key 后自动切换为通义千问真实调用；留空时使用本地示例。
① 上传卷子，识别题目
上传整张卷子的照片（可多张），系统会识别全部文字、自动清理标签并按题号拆成一道道题。
💡 建议：先用「扫描全能王」把卷子扫描清晰、裁切干净再上传，识别效果最好。
没有图片？点这里粘贴卷子文字
填入上方 API Key 后将调用通义千问 qwen-vl-ocr 真实识别；未填写时用本地示例演示流程。
② 勾选做错的题已选 0 题
点题号即可勾选/取消做错的题（做对的不用管）。点右侧 👁 可展开看该题内容。
